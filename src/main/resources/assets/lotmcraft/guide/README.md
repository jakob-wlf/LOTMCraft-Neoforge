# Guiding Book content

Every `.json` file in `chapters/` is one chapter. Chapters are sorted by `order`; each one gets
a title page, a tab on the book's edge and a line in the table of contents. Pages are laid out
automatically: just append elements and they flow onto as many pages as needed.

Content is re-read whenever the book is opened, so after editing press **F3+T** in-game and reopen it.
Broken elements show up in red in the book and are logged.

## Chapter file

```json
{
  "order": 35,
  "title": "guide.lotmcraft.my_chapter.title",
  "icon": "lotmcraft:brewing_cauldron",
  "color": "#2D5E8E",
  "quote": "guide.lotmcraft.my_chapter.quote",
  "cover_entity": "lotmcraft:spirit_dervish",
  "elements": [
    "guide.lotmcraft.my_chapter.intro",
    { "type": "heading", "text": "Literal text works too" }
  ]
}
```

`quote` and `cover_entity` are optional. Without `cover_entity` the title page shows the icon as a
turning 3D model. Text fields take a lang key (preferred, so the book can be translated) or literal text.

## Elements

| type | fields |
|---|---|
| *(plain string)* | shorthand for a `text` element |
| `text` | `text`, optional `align` (`left`/`center`), `scale` |
| `heading` | `text` |
| `steps` | `steps`: list of texts, drawn as a numbered list |
| `note` | `text`, optional `style` (`tip`, `warning`, `lore`), `title` |
| `items` | `items`: item ids shown as slots with tooltips, optional `caption` |
| `model` | `item`: id or list (cycles every 3s), optional `height` (64), `caption` |
| `entity` | `entity`: id or list (cycles), optional `height` (72), `caption` |
| `entity_grid` | `entities`: ids or `{ "id": ..., "note": ... }`, optional `columns` (3). Hover text comes from `guide.<namespace>.entity.<path>` if that key exists |
| `keybinds` | `binds`: list of `{ "key": "key.beyonders.use_ability", "text": ... }`, shows the player's current binding |
| `crafting` | `recipe`: crafting recipe id, optional `caption` |
| `potion_recipe` | optional `sequence`, `pathway`, `caption`; cycles through matching brewing recipes |
| `link` | `chapter`: chapter file name (or `namespace:name`), `text` |
| `redacted` | optional `lines` (3), `stamp`, `tooltip` |
| `image` | `texture`, `width`, `height`, optional `tex_width`, `tex_height`, `caption` |
| `spacer` | `height` |
| `divider` | — |
| `page_break` | — |

New element types can be registered from code with `GuideElements.register(...)`.

## Text markup

| markup | result |
|---|---|
| `**bold**` | bold |
| `*italic*` | italic |
| `[[text]]` | highlighted in red ink |
| `~~text~~` | redacted (scrambled, black) |
| `{c:2D5E8E}text{/c}` | custom colour |
| `{key:key.beyonders.pathway_infos}` | the key the player has bound, e.g. `[J]` |
| `{item:lotmcraft:brewing_cauldron}` | the item's name |
| `{entity:lotmcraft:spirit_dervish}` | the entity's name |
| `\n` | line break |

## Textures

The book's textures live in `textures/gui/guide/` and are generated by `gen_textures.py` there
(`python gen_textures.py`, needs Pillow).
